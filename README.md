# 🚀 NexMeet

NexMeet is a modern full-stack event management platform that allows users to discover, book, and manage events seamlessly. It provides secure authentication, online ticket booking, payment integration, and dedicated dashboards for both users and organizers.

> **Current Status:** Backend Completed ✅ | Frontend Development In Progress 🚧

---

## ✨ Features

### 👤 Authentication
- User Registration & Login
- JWT Authentication
- Protected Routes
- Password Encryption (bcrypt)

### 🎟️ Event Management
- Create Events
- Update Events
- Delete Events
- Browse All Events
- View Event Details

### 🎫 Booking System
- Book Event Tickets
- Booking History
- Booking Validation

### 💳 Payments
- Razorpay Payment Integration
- Secure Payment Verification

### 📊 Dashboard
- User Dashboard
- Organizer Dashboard
- Event Management
- Booking Management
